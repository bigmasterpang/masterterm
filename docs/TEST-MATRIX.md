### 前置条件

- 主程序构建产物位于 `build-release\`（Debug 用 `build-msvc-webview2-native\`）。
- 退出测试依赖配置 `closeBehavior = "exit"`，脚本会自动临时改写并还原
  `%APPDATA%\MasterSSH\MasterSSH.json`。
- SSH 密钥若被 OpenSSH 拒绝（"Bad permissions"），先修复权限：
  ```powershell
  icacls "$env:USERPROFILE\.ssh\id_rsa" /inheritance:r /grant:r "$env:USERNAME:F"
  ```
- RDP 嵌入式控件需要 mstscax.dll 已注册（管理员执行 `regsvr32 C:\Windows\System32\mstscax.dll`）。
- 任何测试结果中不得记录密码、私钥内容或令牌。

## 3. 手工测试步骤

> 每个用例执行后，在「结果记录」表中回填：日期、版本、结果（PASS/FAIL）、
> 现象与日志位置。日志目录以程序设置页显示的路径为准。

### 3.1 SSH 连接

1. 新建 SSH 连接：填写测试服务器地址、端口 22、测试用户名及私钥路径。
2. 双击连接，等待指纹确认提示，接受并登录。
3. 执行 `echo 中文测试`、`top`（观察备用屏幕）、`vim` 后退出，确认终端无乱码和残留状态。
4. 断开（Ctrl+D 或输入 `exit`），确认终端提示已断开；再重连一次。
5. 断开网络（拔线/防火墙临时阻止），确认有重连提示；恢复网络后确认可重连。

### 3.2 SFTP 文件传输

1. 在 SSH 会话打开 SFTP 面板，确认默认进入远端用户目录。
2. 本机新建测试文件集：
   - `中文 文件.txt`、`emoji😀.txt`、`(括号) [方括号].txt`、`空格 名称.log`
   - 深层目录 `a/b/c/d/e/文件.txt`（5 层以上）
3. 上传整个目录到 `/tmp/mt-matrix-<日期>`，确认传输中心显示进度、速度和完成状态。
4. 刷新远端列表并下载回本机另一目录，比对文件名逐一一致（含中文/Emoji/括号/空格）。
5. 删除远端测试目录，确认删除任务成功。
6. 上传中途点击「取消」，确认任务进入失败列表且可「重试」。
7. 双击一个远端 `.txt` 文件编辑保存，确认自动同步回远端且内容一致。
8. 准备包含多个大文件的目录，开始递归上传或下载；传输进行到中途后退出程序，
   重新启动并选择「继续全部」，确认完整文件被跳过、部分文件从已有大小继续，
   传输中心显示逐文件进度且最终文件大小一致。开启「传输后校验」时，确认校验失败
   会显示具体文件名而不是静默覆盖。

### 3.3 RDP（VMware 虚拟机）

1. 新建 RDP 连接：VMware 虚拟机地址（内网 IP），填写账号密码（不写入本文档）。
2. 连接成功并登录后，观察首帧是否清晰（局域网应默认 32 位色 + LAN 策略）。
3. 在连接日志中确认颜色深度、智能缩放、性能标志、连接类型有实际回读值。
4. 来回切换 SSH 标签与 RDP 标签 20 次，确认无黑屏、无错误遮罩、无错误标签内容。
5. 进入全屏再退出 5 次，确认无重复协商闪烁、无黑屏。
6. 固定/取消固定左侧连接栏，确认 RDP 可视区域正确适配。
7. 打开设置弹窗、连接编辑弹窗并展开 RDP 高级配置，确认弹窗不被 RDP 层遮挡、圆角无残留。
8. 虚拟机重启（模拟掉线），确认断线提示后可用「重连」恢复。
9. 同时打开两个 RDP 标签到同一台虚拟机，分别操作确认互不串扰；关掉其一确认另一台正常。

### 3.4 DPI 缩放

1. 设置 Windows 缩放为 125%，重新登录（或注销重登）后启动程序：
   - 确认主界面、弹窗、SFTP 面板不模糊、不错位。
   - 连接 RDP 确认远端分辨率适配正确。
2. 依次在 150%、200% 重复第 1 步。
3. 恢复 100%，确认无残留异常。
4. 双显示器（若有）测试：把窗口拖到不同 DPI 的显示器，确认界面正常。

### 3.5 中文与特殊路径

1. 在 3.2 的 SFTP 用例中已覆盖文件名部分；额外确认：
   - 终端中 `ls` 显示中文文件名正常（UTF-8）。
   - 复制粘贴中文到远端 `cat > 文件` 后读回一致。
2. 长路径：在远端创建 ≥200 字符的目录名，确认列表、下载和远程编辑可用。
3. 本机路径含中文/空格（如 `C:\Users\<用户>\Documents\测试 目录`）下打开 SFTP
   本机面板，确认列表正常。

### 3.6 串口

1. 有真实串口设备时：新建串口连接，按设备参数（波特率等）连接，发送/接收数据确认正常。
2. 无设备时：仅运行 `MasterTermNativeSerialTest.exe`（枚举/参数解析测试）。
3. 断开串口线缆（或拔下 USB 转串口），确认程序提示断线且不崩溃；插回后可重连。

### 3.7 本地终端（ConPTY）

1. 新建本地终端，确认打开 `cmd.exe` 且提示符正常。
2. 运行 `powershell`、`ping 127.0.0.1 -n 3` 确认无乱码。
3. 运行 `diskpart`（需管理员，若可用）或 `wsl`（若已安装）观察交互输出。
4. 关闭标签，确认无残留 cmd/conhost 进程（任务管理器核对）。
